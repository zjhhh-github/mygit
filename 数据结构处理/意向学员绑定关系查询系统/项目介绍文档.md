# 意向学员绑定关系查询系统 - 项目介绍文档

## 1. 项目概述

本目录当前以 **导入控制台** 为核心，集成多条数据流水线（Excel 增量导入、内部备注、飞书同步、用户上传、定时拷贝等）。

另保留 **db_viewer.py** 作为独立的「售前通讯录查询」桌面工具（含 `modules/` 子包）。

---

## 2. 核心脚本（导入控制台依赖）

| 脚本 | 用途 |
|------|------|
| `导入控制台.py` | 统一 GUI 入口 |
| `增量导入.py` | 售前 Excel → 数据处理/查重清洗 → Supabase 增量导入 |
| `内部备注导入.py` | contact.db → internal_notes UPSERT |
| `意向学员关系导入到飞书多维表格.py` | 意向学员数据同步飞书多维表格 |
| `上传用户结构.py` | 飞书用户表 → 秒哒 import-users |
| `定时拷贝任务.py` | contact.db 等文件定时拷贝 |
| `task_runner.py` | 全局任务队列 |
| `custom_plugins.py` | 扩展功能插件框架 |

---

## 3. 独立工具

| 脚本 | 用途 |
|------|------|
| `db_viewer.py` | 售前通讯录 SQLite 查询/导出（`python db_viewer.py`） |
| `modules/prospective/` | db_viewer 重构子模块 |
| `示例插件.py` | 扩展功能插件示例 |

---

## 4. 配置与打包

| 文件 | 用途 |
|------|------|
| `custom_plugins.json` | 扩展功能配置 |
| `copy_tasks.json` | 定时拷贝任务列表 |
| `feishu_sync_console_config.json` | 飞书同步脚本路径等 |
| `导入控制台.spec` / `打包.ps1` | PyInstaller 打包 |

运行时还会生成：`note_import_console_config.json`、`tab1_console_config.json`、`user_upload_console_config.json` 等。

---

## 5. 运行方式

### 导入控制台（推荐）

```powershell
cd D:\git\mygit\数据结构处理\意向学员绑定关系查询系统
python 导入控制台.py
```

### 售前通讯录查询（独立）

```powershell
cd D:\git\mygit\数据结构处理\意向学员绑定关系查询系统
python db_viewer.py
```
