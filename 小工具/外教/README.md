# 外教群查询与回写工具集

本文件夹包含四个配合使用的小工具，用于**通过微信联系人信息判断学员所在的外教群**，并把结果批量回写到飞书多维表格：

1. `查询外教群.py`：交互式/命令行小工具，输入一个联系人关键词，查询这个人在本地微信联系人库中所在的外教群（群名含大写 `CT` 或 `XXJ`），支持一键拷贝最新数据库。
2. `飞书回写外教群.py`：批量工具，直接读取飞书多维表格里的学员编号，用编号去精确匹配微信联系人，自动判断"是否有外教群"和"外教群名"，并回写到飞书表格。
3. `拷贝路径设置_GUI.py`：可视化小工具，用来修改上面两个脚本"拷贝最新数据库"这一步用到的源文件路径（比如换一台电脑，源路径盘符不一样），不用直接改代码。
4. `外教群工具箱_GUI.py`：**把工具 2「飞书批量回写」「全量核对更新」和工具 3「拷贝路径设置」合并进同一个窗口**的可视化整合版，打包成一个 exe 就能用，不需要再打开命令行。

典型使用场景：日常想临时查一个学员在哪个外教群，用工具 1（命令行）；需要给飞书表格里一批学员批量补全"外教群"信息、或者需要顺手改一下拷贝路径，且不想用命令行，直接用工具 4 打包出的一个 exe 即可（内部就是工具 2 + 工具 3）。

## 一、查询外教群.py

### 功能说明

- 输入联系人关键词（微信ID / 微信号 / 备注 / 昵称，任意一个包含即可），在本地微信 `contact.db` 中搜索匹配的联系人。
- 对每个匹配到的联系人，查询它在内部专用微信库中属于哪些"外教群"（群昵称中包含大写 `CT` 或 `XXJ` 才算外教群）。
- 支持一次性传关键词直接查询，也支持不传关键词进入交互式循环查询模式。
- **默认每次查询前都会自动**从本机 chatlog 存储目录（`C:\Users\LENOVO\Documents\chatlog\...`）拷贝最新的「内部专用」「内部专用2」两个数据库到本地，避免用到过期数据；如果源文件不存在，或者只想用本地已有的数据库文件，加 `--skip-copy-db` 跳过这一步。
- 这两个源路径如果要改（比如换到另一台电脑，源文件变成挂载的网络盘），不需要改代码，用第三个工具 `拷贝路径设置_GUI.py` 可视化修改即可，见下方「三、拷贝路径设置_GUI.py」章节。

### 使用方法

路径说明：脚本位于 `小工具/外教/` 目录下，需要在该目录下执行。

推荐执行方式（从项目根目录 `D:\git\mygit` 进入）：

```powershell
cd D:\git\mygit\小工具\外教
python 查询外教群.py 张三
```

上面这条命令默认会先自动拷贝最新的两个内部专用数据库，再执行查询。其他常用用法：

```powershell
# 自定义数据库路径（多个用分号分隔）
python 查询外教群.py 张三 --db "C:\a.db;C:\b.db"

# 跳过自动拷贝数据库这一步，直接用本地已有的数据库文件查询
python 查询外教群.py 张三 --skip-copy-db

# 不传关键词，进入交互式循环查询模式（连续查多个人，输入 q 退出；默认也会先自动拷贝数据库）
python 查询外教群.py
```

### 默认数据库路径

- `C:\Users\LENOVO\Desktop\contact.db`
- `C:\Users\LENOVO\Desktop\contact_内部专用.db`
- `C:\Users\LENOVO\Desktop\contact_内部专用2.db`

外教群关系（`chat_room` / `chatroom_member`）只存在于「内部专用」「内部专用2」这两个库。

### 输出结果

在终端打印每个匹配联系人的：微信ID（`username`）、微信号（`alias`）、备注（`remark`）、昵称（`nick_name`）、外教群、来源数据库。

### 验证方式

用一个已知在外教群里的联系人关键词查询，确认打印出来的"外教群"字段和实际微信群聊里的群名一致。

## 二、飞书回写外教群.py

### 对应的飞书多维表格

<https://ipcjg02m9k.feishu.cn/base/Zk05bwki2abD8XsBBOccaFsPn8e?table=tbljyq4wU1jONHGC&view=vewWwgXYys>

- `app_token` = `Zk05bwki2abD8XsBBOccaFsPn8e`
- `table_id` = `tbljyq4wU1jONHGC`
- `view_id` = `vewWwgXYys`（默认批量处理模式用这个视图；脚本只读取这个视图下的记录，视图本身的筛选/排序条件会生效）
- 「全量核对更新」模式（`--recheck-only`）默认用另一个视图 `view_id = vewtEfMDuj`，详见下方「另一种模式：全量核对更新」章节。

### 功能说明

1. **精确匹配学员**：读取飞书表格「编号」列（6 位学员编号），用 `¿¿¿ + 编号` 去本地微信联系人库搜索。之所以用编号而不是姓名搜索，是因为微信内部专用备注固定格式是「¿¿¿编号-孩子中文全名」（例如 `¿¿¿005411-亓书琦`），编号在飞书表里全表唯一，按姓名搜容易因为重名（比如多个学员都叫"依诺"）而匹配到好几个不相关的人。

2. **按外教平台过滤，判断是否有外教群**：汇总该学员命中的所有外教群（可能同时有 CT 群和 XXJ 群）。如果飞书「外教平台」列已经登记了具体平台（CT 或 XXJ），就只看属于这个平台的群，其他平台的群直接忽略：

   | 属于该平台的群数量 | 是否有外教群 | 外教群名 |
   | --- | --- | --- |
   | 0 个，且外教平台不为空 | 否 | `孩子中文全名 + " " + 外教平台`（如 `张三 CT`） |
   | 0 个，且外教平台为空 | 否 | 空字符串（不返回任何内容） |
   | 唯一 1 个 | 是 | 该唯一群名 |
   | 2 个及以上（无法唯一确定） | 不唯一 | 属于该平台的所有群名，用"、"拼接全部列出 |

   若「外教平台」列本身是空的，则不做过滤，直接用命中的全部群名按上表逻辑判断。

3. **补默认值「开始材料」**：「开始材料」单选列目前只有一个选项「WOW L 系列 001」。只有同时满足「该字段当前为空」「本次算出的外教群名不为空」且「是否有外教群 = 否」时，才会补上这个默认值：
   - 「是否有外教群 = 是」，说明已经唯一确定外教群，不再需要补默认值；
   - 「是否有外教群 = 不唯一」，说明查到多个外教群、需要人工核实，也不补默认值；
   - 已经手动填过的记录不会被覆盖，外教群名为空的记录也不会被强行填上默认值。

4. **补默认值「充值课时」**：「充值课时」是数字字段，只在「该字段当前为空」且「是否有外教群 = 否」时，才会补默认值 `144`（判定为「是」「不唯一」都不补）；已经手动填过的记录不会被覆盖。

5. **回写飞书**：把「是否有外教群」「外教群名」（以及需要时的「开始材料」「充值课时」）写回飞书对应记录。「是否有外教群」是单选字段，若「不唯一」这个选项还不存在，飞书接口会在写入时自动新建该选项（无需手动改字段配置）。

### 安全机制：默认写入模式，可加 `--preview` 切回预览

**默认是「写入模式」**：不加任何参数直接运行，就会真正调用飞书接口写入计算结果。如果只想先看看计算结果、不真正写入飞书，加 `--preview` 参数即可（只打印将要写入的内容，不调用写入接口）。

> ⚠️ 由于默认就会写入线上数据，第一次运行、或者改动过判定逻辑之后，建议先加 `--preview --limit 5` 小范围验证结果无误，再去掉这两个参数正式跑全量。

### 另一种模式：全量核对更新（`--recheck-only`）

日常这张飞书表格可能已经有一批历史数据（不管是之前跑过本脚本写的，还是人工改过的），如果只是想**做一次全量核对纠错，又不想影响已经人工处理好的「开始材料」「充值课时」**，可以加 `--recheck-only` 参数，切换到「全量核对更新」模式，跟默认模式的区别：

> 注意：「全量核对更新」模式默认读取的视图是 `vewtEfMDuj`，跟默认批量处理模式的默认视图 `vewWwgXYys` **不是同一个**；如果想核对别的视图，用 `--view-url`（或 GUI 里的「自定义飞书视图」输入框）临时指定即可，不用改代码。

| | 默认模式 | 全量核对更新模式（`--recheck-only`） |
| --- | --- | --- |
| 涉及字段 | 「是否有外教群」「外教群名」+「开始材料」「充值课时」 | 只有「是否有外教群」「外教群名」 |
| 是否强制写入 | 每条都会写入，不管算出来的结果跟表里现有值是否一样 | 先跟表里现有值逐字比较，**一样就跳过**（不调用写入接口），不一样才更新 |

```powershell
cd D:\git\mygit\小工具\外教

# 全量核对更新 + 预览：只打印哪些记录跟当前微信群情况不一致，不会写入飞书
python 飞书回写外教群.py --recheck-only --preview

# 确认无误后正式更新：把核对到的不一致记录写回飞书（一致的记录不会被触碰）
python 飞书回写外教群.py --recheck-only

# 全量核对更新 + 自定义飞书视图：核对默认表格之外的另一张表 / 另一个视图
# --view-url 直接粘贴浏览器地址栏复制的完整视图链接即可，不用改代码
python 飞书回写外教群.py --recheck-only --preview --view-url "https://xxx.feishu.cn/base/xxx?table=yyy&view=zzz"
```

`--view-url` 只在 `--recheck-only` 模式下生效，默认批量处理模式（不加 `--recheck-only`）不支持自定义视图，仍然固定写死的表格。

### 使用方法

路径说明：脚本位于 `小工具/外教/` 目录下，需要在该目录下执行，且脚本会直接 `import` 同目录的 `查询外教群.py`（复用其中的联系人搜索、外教群索引构建逻辑），两个文件必须放在一起。

```powershell
cd D:\git\mygit\小工具\外教

# 预览模式 + 只处理前 5 条：只打印计算结果，不写入飞书（建议先跑一次确认结果无误）
python 飞书回写外教群.py --limit 5 --preview

# 默认写入模式：直接真正写入飞书（不加参数就是这个效果）
python 飞书回写外教群.py

# 自定义微信数据库路径（多个用分号分隔）
python 飞书回写外教群.py --db "C:\a.db;C:\b.db"

# 跳过自动拷贝数据库这一步，直接用本地已有的数据库文件
python 飞书回写外教群.py --skip-copy-db
```

### 关于自动拷贝数据库

**每次运行都会先自动**从本机 chatlog 存储目录拷贝最新的「内部专用」「内部专用2」两个数据库到本地（复用 `查询外教群.py` 的拷贝逻辑），保证判断外教群用的是最新数据。如果源文件不存在、或者想跳过这一步直接用本地已有的数据库文件，加 `--skip-copy-db` 参数即可。

### 命令行参数一览

| 参数 | 说明 |
| --- | --- |
| `--db` | 自定义微信 `contact.db` 路径，多个用分号分隔（不填则用 `查询外教群.py` 里的默认路径） |
| `--skip-copy-db` | 跳过自动拷贝数据库这一步 |
| `--limit N` | 只处理前 N 条记录，便于先小范围验证效果（默认 0 表示处理全部） |
| `--preview` | 预览模式：只打印结果、不写入飞书；不加此参数时默认直接写入飞书 |
| `--recheck-only` | 切换到「全量核对更新」模式：只核对/更新「是否有外教群」「外教群名」，一致则跳过、不一致才更新，不涉及「开始材料」「充值课时」（不加此参数走默认批量处理模式） |
| `--view-url` | 仅在 `--recheck-only` 模式下生效：自定义要核对的飞书视图链接（浏览器地址栏直接复制），不填则用脚本里写死的默认表格/视图 |

### 输出结果

控制台按顺序打印每条记录的处理结果，例如：

```
[1/893] 亓书琦（编号=005411） → 是否有外教群=否，外教群名=张三 CT，开始材料→WOW L 系列 001，充值课时→144
```

结束后打印汇总统计：总记录数、跳过条数、"是/否/不唯一"各自的条数、"开始材料"和"充值课时"补默认值的条数，以及（写入模式时）实际写入成功/失败的条数。

### 验证方式

1. 先加 `--preview --limit 5` 只预览前 5 条，检查控制台打印的判断结果是否符合预期，尤其关注 `不唯一`（多个外教群，需要人工核实）的记录。
2. 确认无误后去掉 `--preview --limit 5`，直接运行（默认就是写入模式），写入完成后打开[飞书表格](https://ipcjg02m9k.feishu.cn/base/Zk05bwki2abD8XsBBOccaFsPn8e?table=tbljyq4wU1jONHGC&view=vewWwgXYys)，检查「是否有外教群」「外教群名」「开始材料」「充值课时」几列是否已按预期填充。
3. 也可以先用 `--limit 5`（不加 `--preview`）只真正写入前 5 条做小范围验证，确认没问题后再对全量执行。

### 打包为 exe（可选，不装 Python 环境也能双击运行）

已提供打包配置 `spec/飞书回写外教群.spec`，打包出的 exe 是**控制台程序**（保留黑框窗口），运行时会把脚本的全部日志实时打印在这个窗口里，跟直接用 `python 飞书回写外教群.py` 运行时看到的输出完全一样。

路径说明：打包配置位于 `小工具/外教/spec/` 目录下，打包命令需要在 `小工具/外教/` 目录下执行（这样 `dist/`、`build/` 才会生成在正确位置）。

推荐执行方式（从项目根目录 `D:\git\mygit` 进入）：

```powershell
cd D:\git\mygit\小工具\外教
py -3.14 -m PyInstaller "spec\飞书回写外教群.spec" --distpath "dist" --workpath "build" --noconfirm
```

打包完成后，exe 文件在 `小工具\外教\dist\飞书回写外教群.exe`，用法与直接跑脚本完全一致，可以在命令行里带参数运行：

```powershell
cd D:\git\mygit\小工具\外教\dist
.\飞书回写外教群.exe --limit 5 --preview   # 预览模式，只处理前 5 条，不写入飞书
.\飞书回写外教群.exe                       # 默认写入模式，直接正式写入飞书
```

也可以直接双击 `飞书回写外教群.exe`（等价于不带任何参数运行，即**全量写入模式**，会真正写入飞书，务必谨慎），运行结束后窗口会停留显示日志，手动关闭窗口即可。

注意：exe 是本机打包产物，不建议提交到 git 仓库（`build/`、`dist/` 属于生成物，可按需清理，不影响源码）。

### 注意事项

- 「编号」为空的记录无法用编号搜索，会按"没有外教群"处理，控制台会打印提示。
- 只有生产环境的飞书应用凭证（`APP_ID` / `APP_SECRET`）才能访问对应的多维表格，默认写死在脚本里（与 `manjike-tools/feishu_download` 共用同一应用），也可以用环境变量 `FEISHU_APP_ID` / `FEISHU_APP_SECRET` 覆盖。
- 这张飞书表格是团队日常在用的活表，记录数量、字段内容可能随时因为他人操作而变化，属于正常现象。

## 三、拷贝路径设置_GUI.py

### 功能说明

可视化修改「查询外教群.py」「飞书回写外教群.py」共用的"拷贝最新数据库"这一步的源文件路径，不用直接改代码。

- **快速选择预设方案**：一键切换两种常见情况：
  - 「内部专用（本机路径）」：源路径是本机 chatlog 存储目录（`C:\Users\LENOVO\Documents\chatlog\...`）；
  - 「其他设备（网络盘 Z:）」：源路径是挂载的网络盘（`Z:\Documents\chatlog\...`），适用于换到其他电脑、chatlog 数据是通过网络盘访问的情况。
- **手动编辑**：每个任务的源路径、目标路径都可以直接在输入框里改，也可以点「浏览...」用文件选择框选。
- **立即测试拷贝**：不用保存，直接按当前填写的路径试跑一次真实拷贝，用弹窗告诉你成功/失败，方便先验证路径对不对。
- **保存并应用**：保存后写入 Windows 注册表（不会在文件夹里产生额外的配置文件）。`查询外教群.py` 和 `飞书回写外教群.py` 下次运行时会自动读取并使用这里保存的路径；如果从没保存过，两个脚本仍然使用代码里写死的默认路径（内部专用·本机路径）。

### 使用方法

路径说明：脚本位于 `小工具/外教/` 目录下，需要在该目录下执行，且脚本会直接 `import` 同目录的 `查询外教群.py`（复用其中的注册表读写、拷贝执行逻辑）。

```powershell
cd D:\git\mygit\小工具\外教
python 拷贝路径设置_GUI.py
```

### 验证方式

1. 打开界面后，点一下另一个预设方案（比如从「内部专用」切到「其他设备」），确认输入框里的路径确实变了。
2. 点「立即测试拷贝」，看弹窗提示的每个任务是「成功」还是「源文件不存在」，据此判断路径是否正确。
3. 确认路径无误后点「保存并应用」，然后运行一次 `python 查询外教群.py 张三`（或 `飞书回写外教群.py --preview --limit 1`），观察控制台打印的拷贝结果，确认走的是刚保存的新路径。

### 注意事项

- 保存的配置是"每台电脑独立"的（存在当前 Windows 用户的注册表里），换电脑运行需要重新用这个工具设置一次路径（或者直接用默认的「内部专用」预设）。
- 两个任务分别对应「内部专用」「内部专用2」两个数据库，目标路径一般不需要改（固定是 Desktop 下的 `contact_内部专用.db` / `contact_内部专用2.db`），主要改的是源路径。

## 四、外教群工具箱_GUI.py（合并版，推荐日常使用）

### 功能说明

把「二、飞书回写外教群.py」的两种模式和「三、拷贝路径设置_GUI.py」**合并进同一个窗口**，打包成一个 exe 后不需要再打开命令行、不需要记任何 `--xxx` 参数：

- **「飞书批量回写」标签页**：对应默认批量处理模式。界面上直接填参数（自定义数据库路径 / 只处理前 N 条 / 是否跳过拷贝 / 是否预览模式），点「开始运行」，运行日志实时显示在窗口下方的文本框里，效果和命令行运行 `飞书回写外教群.py` 完全一样，只是不用打字敲参数。
  - 每条记录都会强制写入「是否有外教群」「外教群名」，并顺带给「开始材料」「充值课时」补默认值。
  - 默认勾选「预览模式」，避免误触发真实写入；确认结果无误后取消勾选再运行一次才会真正写入飞书。
  - 点「开始运行」时如果没勾选「预览模式」，会先弹窗二次确认，避免手滑误操作。
- **「全量核对更新」标签页**：对应命令行 `--recheck-only` 模式，界面参数在「飞书批量回写」的基础上多了一个「自定义飞书视图」输入框（对应命令行 `--view-url`），留空核对默认表格，填入浏览器地址栏复制的完整视图链接就能核对别的表 / 别的视图，不用改代码。只核对/更新「是否有外教群」「外教群名」两列：重新算一次结果，跟飞书表里现有值逐字比较，**一样就跳过**（不调用写入接口），不一样才更新；不会碰「开始材料」「充值课时」等其他字段。适合日常对这张飞书表做一次全量核对纠错，同样默认勾选「预览模式」、正式更新前会弹窗二次确认。
- **「拷贝路径设置」标签页**：内容跟独立运行 `拷贝路径设置_GUI.py` 完全一样（同一份代码，只是嵌入到了标签页里），可以直接切换预设方案 / 手动改路径 / 测试拷贝 / 保存。

三个标签页背后复用的都是 `飞书回写外教群.py`、`拷贝路径设置_GUI.py`、`查询外教群.py` 里已有的函数，本文件不重复实现任何业务逻辑，只是做界面整合。

### 使用方法

路径说明：脚本位于 `小工具/外教/` 目录下，需要在该目录下执行，且会 `import` 同目录的另外三个 `.py` 文件，四个文件必须放在一起。

```powershell
cd D:\git\mygit\小工具\外教
python 外教群工具箱_GUI.py
```

### 打包为 exe

已提供打包配置 `spec/外教群工具箱_GUI.spec`，打包出的 exe 是**纯 GUI 程序**（`console=False`，不会弹出黑框），运行日志显示在窗口内置的日志文本框里。

```powershell
cd D:\git\mygit\小工具\外教
py -3.14 -m PyInstaller "spec\外教群工具箱_GUI.spec" --distpath "dist" --workpath "build" --noconfirm
```

打包完成后，双击 `小工具\外教\dist\外教群工具箱.exe` 即可使用，不需要再单独打包 `飞书回写外教群.py` 或 `拷贝路径设置_GUI.py`。

> 提示：exe 文件在资源管理器里显示的图标、以及窗口运行时标题栏 / 任务栏显示的图标，都是白底黑字「外教建群」四个字（`spec/外教建群_icon.ico`）。窗口运行时的图标是代码里显式设置的（`root.iconbitmap()`），图标文件也打包进了 exe 里（见 `spec/外教群工具箱_GUI.spec` 的 `datas` 配置），所以不需要额外携带图标文件、也不依赖系统图标缓存刷新。

### 验证方式

1. 打开界面后先切到「拷贝路径设置」标签页，确认能看到当前生效的路径（跟独立运行 `拷贝路径设置_GUI.py` 看到的内容一致）。
2. 切到「飞书批量回写」标签页，「只处理前 N 条」填 `1`，保持「预览模式」勾选，点「开始运行」，确认日志框里能看到跟命令行 `飞书回写外教群.py --limit 1 --preview` 完全一样的输出内容。
3. 切到「全量核对更新」标签页，保持「预览模式」勾选，点「开始运行」，确认日志框里能看到跟命令行 `飞书回写外教群.py --recheck-only --preview` 完全一样的输出内容（每条记录会打印「一致跳过」还是「不一致需要更新」）。
4. 确认无误后取消勾选「预览模式」，点「开始运行」，会先弹窗二次确认，确认后才会真正写入飞书；写入完成后打开[飞书表格](https://ipcjg02m9k.feishu.cn/base/Zk05bwki2abD8XsBBOccaFsPn8e?table=tbljyq4wU1jONHGC&view=vewWwgXYys)核对结果。

### 注意事项

- 运行期间「开始运行」按钮会禁用并显示"运行中..."，避免同时点两次导致重复运行；运行结束后按钮会自动恢复。
- 日志文本框是只读的（不能手动编辑内容），可以点「清空日志」手动清空，方便看清楚下一次运行的输出。
- 这个整合版本身不会修改 `飞书回写外教群.py` / `拷贝路径设置_GUI.py` 的独立运行方式，两个文件仍然可以按原来的方式单独运行、单独打包。
