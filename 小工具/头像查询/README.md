# 头像查询工具集

本文件夹包含两个配合使用的小工具，用于**通过微信联系人信息定位并识别本地缓存的头像图片**：

1. `导出用户名md5映射.py`：从微信联系人数据库导出 `username -> md5(username)` 映射表，因为微信本地缓存的头像图片文件名就是 `md5(username)`。
2. `find_similar_images.py`：在一批头像图片中，找出与某张已知头像相似的图片。
3. `头像查询工具箱_GUI.py`：**把工具 1 和工具 2 合并进同一个窗口**的可视化整合版，可在界面上选择数据库、选择图片、选择文件夹，打包成一个 exe 就能用。

典型使用场景：已经通过某种方式拿到了一批头像缓存图片（文件名是一串 md5 值，看不出是谁），先用工具 1 把 `username`、`alias`（微信号）、`remark`（备注名）、`nick_name`（微信昵称）和 `md5` 对应起来，就能知道某个 md5 文件名对应的是哪个联系人；如果某张头像文件名对不上、或者想找长得像的头像，再用工具 2 做图片相似度比对。日常不想记命令行参数时，直接用工具 3 或打包后的 exe。

## 一、导出用户名md5映射.py

### 功能说明

- 读取桌面上两个微信联系人数据库（SQLite 格式）：
  - `C:\Users\LENOVO\Desktop\contact_内部专用.db`
  - `C:\Users\LENOVO\Desktop\contact_内部专用2.db`
- 从两个数据库的 `contact` 表中读取以下字段：
  - `username`：微信内部唯一标识（wxid 或第三方账号），头像缓存文件名就是这个字段的 md5 值
  - `alias`：微信号（用户自己设置的对外显示账号，可能为空）
  - `remark`：备注名（自己给联系人打的备注，可能为空）
  - `nick_name`：微信昵称（对方自己设置的昵称，可能为空）
- 对每个 `username` 计算 MD5（32位小写十六进制，UTF-8 编码）
- 按 `username` 去重（两个数据库中重复的 `username`，只保留第一次出现的记录）
- 导出为 CSV 文件，方便用 Excel 或表格工具搜索、筛选

### 使用方法

路径说明：脚本位于 `小工具/头像查询/` 目录下，需要在该目录下执行。

推荐执行方式（从项目根目录 `D:\git\mygit` 进入）：

```powershell
cd D:\git\mygit\小工具\头像查询
python 导出用户名md5映射.py
```

如果当前已经在 `小工具\头像查询` 目录下，直接执行：

```powershell
python 导出用户名md5映射.py
```

### 输出结果

在脚本所在目录生成 `username_md5_mapping.csv`，包含六列：

| 列名 | 说明 |
| --- | --- |
| 来源数据库 | 这条记录来自哪个 `.db` 文件 |
| username | 微信内部唯一标识 |
| alias | 微信号（可能为空） |
| remark | 备注名（可能为空） |
| nick_name | 微信昵称（可能为空） |
| md5 | `username` 的 MD5 值，对应头像缓存文件名 |

### 验证方式

打开 `username_md5_mapping.csv`，任选一行，用 Python（或在线 md5 工具）对该行的 `username` 计算 MD5，结果应与 `md5` 列一致；同时可以对照 `remark`/`alias` 列，确认能否辨认出对应的联系人。

### 注意事项

- 数据库路径写在脚本顶部的 `DB_PATHS` 常量里，如果桌面数据库文件名或位置变了，需要同步修改这里。
- `alias`、`remark`、`nick_name` 属于可选字段：如果某个数据库的 `contact` 表没有这几列，脚本会打印提示并把对应内容留空，不会报错中断。
- 部分 `remark` 中可能出现 `¿¿¿` 这类字符，这是原始数据库里本身存储的内容（怀疑是原始导出工具把某个特殊符号/表情误编码成了这个字符），并非本脚本读取或写入过程中产生的乱码。

## 二、find_similar_images.py（图片相似度查找）

### 功能说明

在一个文件夹中查找与输入图片相似的图片，常用于：拿到一张头像图片，去缓存文件夹里找长得像的其它头像。

处理步骤：

1. 自动检测并移除图片的白色边框
2. 将图片统一调整为 58×58 像素后再比较
3. 使用均方误差（MSE）算法计算相似度
4. 按相似度从高到低，返回最相似的若干张图片

支持的图片格式：JPG、JPEG、PNG、BMP、TIFF、GIF。

### 安装依赖

使用前需要先安装依赖库：

```powershell
pip install pillow numpy
```

### 使用方法

路径说明：脚本位于 `小工具/头像查询/` 目录下，需要在该目录下执行。

```powershell
cd D:\git\mygit\小工具\头像查询
python find_similar_images.py <输入图片路径> <待搜索文件夹路径> [--threshold 阈值] [--top-n 返回数量]
```

参数说明：

- `<输入图片路径>`：用来搜索相似图片的原始图片路径
- `<待搜索文件夹路径>`：包含待比较图片的文件夹路径（例如头像缓存目录）
- `--threshold`：相似度阈值（0~1 之间，默认 0.3），只有相似度高于此值的图片才会被返回
- `--top-n`：返回最相似的图片数量（默认 10）

示例：

```powershell
# 查找相似图片，返回最相似的5张（相似度阈值为0.5）
python find_similar_images.py input.jpg ./images --threshold 0.5 --top-n 5

# 只指定图片和文件夹（使用默认参数）
python find_similar_images.py photo.png ./my_photos
```

### 输出结果

程序会输出找到的相似图片列表，按相似度从高到低排序，格式如下：

```
图片路径: 相似度分数
```

相似度分数范围是 0 到 1，数值越接近 1 表示越相似。

### 验证方式

准备一张已知图片和一个包含它自身（或极相似图片）的文件夹，运行脚本后确认该图片本身出现在结果列表中，且相似度分数接近 1。

## 三、头像查询工具箱_GUI.py（合并版，推荐日常使用）

### 功能说明

把「一、导出用户名md5映射.py」和「二、find_similar_images.py」**合并进同一个窗口**，可在界面上：

- **「导出 MD5 映射」标签页**：点「添加数据库…」选择一个或多个 `.db` 文件，选择 CSV 输出位置，点「开始导出」。
- **「相似图片查找」标签页**：点「浏览…」选择参考图片、选择待搜索文件夹，设置阈值和返回数量，点「开始查找」；结果表格会显示相似度、文件名、备注/昵称（若加载了 MD5 映射 CSV）、完整路径；双击某行可复制完整路径。

### 安装依赖

相似图片查找依赖 `pillow` 和 `numpy`（GUI 本身只用内置 tkinter）：

```powershell
pip install pillow numpy
```

### 使用方法

路径说明：脚本位于 `小工具/头像查询/` 目录下，需要在该目录下执行，且会 `import` 同目录的另外两个 `.py` 文件，三个文件必须放在一起。

推荐执行方式（从项目根目录 `D:\git\mygit` 进入）：

```powershell
cd D:\git\mygit\小工具\头像查询
python 头像查询工具箱_GUI.py
```

### 打包为 exe

已提供打包配置 `spec/头像查询工具箱_GUI.spec`，打包出的 exe 是**纯 GUI 程序**（`console=False`，不会弹出黑框）。

打包前请先安装依赖：

```powershell
pip install pillow numpy pyinstaller
```

打包命令（在 `小工具/头像查询/` 目录下执行）：

```powershell
cd D:\git\mygit\小工具\头像查询
py -3.14 -m PyInstaller "spec\头像查询工具箱_GUI.spec" --distpath "dist" --workpath "build" --noconfirm
```

如果 `py -3.14` 不可用，可改用当前 Python：

```powershell
python -m PyInstaller "spec\头像查询工具箱_GUI.spec" --distpath "dist" --workpath "build" --noconfirm
```

打包完成后，双击 `小工具\头像查询\dist\头像查询工具箱.exe` 即可使用。

注意：exe 是本机打包产物，不建议提交到 git 仓库（`build/`、`dist/` 属于生成物，可按需清理，不影响源码）。

### 验证方式

1. 打开界面后切到「导出 MD5 映射」，添加桌面上的联系人数据库，点「开始导出」，确认日志里显示写入条数，且输出 CSV 能正常打开。
2. 切到「相似图片查找」，选择一张参考图和一个包含相似图片的文件夹，保持默认阈值 0.3，点「开始查找」，确认下方表格出现结果且相似度合理。
3. 若已导出 `username_md5_mapping.csv`，在「MD5 映射 CSV」里选中该文件后再查找，确认「备注/昵称」列能反查出联系人。

### 注意事项

- 运行期间「开始导出 / 开始查找」按钮会禁用，避免重复点击；结束后自动恢复。
- 打包后的 exe 与脚本放在同一目录时，默认 CSV 路径为 exe 所在目录下的 `username_md5_mapping.csv`。
- 工具 1、工具 2 仍可单独用命令行运行，本整合版不会破坏原有脚本用法。
